# Manual Actions

The repository implements the static app, validation, tests, SEO foundation, and deployment configuration.

The owner must still:

1. Confirm the definitive commercial name.
2. Confirm the definitive domain.
3. Replace `PUBLIC_SITE_URL`.
4. Create or review the definitive logo.
5. Review translations before publishing.
6. Review the privacy page.
7. Visually review every template.
8. Connect the repository to Cloudflare Pages.
9. Configure the custom domain.
10. Enable Cloudflare Web Analytics from the dashboard if desired.
11. Verify the deployed site.
12. Register the site in Google Search Console.
13. Submit the sitemap.
14. Test copy/paste in Gmail.
15. Test sample emails on desktop and mobile.
16. Make the repository public only after confirming it contains no secrets.
17. Create real README screenshots.
18. Confirm the final public repository URL and update `NOTICE`.
19. Decide whether to adopt a proprietary visual brand.
20. Plan optional contact collection without implementing it in this MVP.
